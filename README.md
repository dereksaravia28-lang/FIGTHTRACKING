# FightTrack

## Descrição

FightTrack é uma aplicação móvel desenvolvida para ajudar utilizadores a registar e acompanhar os seus treinos de modalidades de combate e treino de força.

A aplicação permitirá guardar sessões de treino, definir objetivos pessoais e consultar estatísticas relacionadas com a evolução desportiva.

---

## Objetivos

- Registar treinos
- Gerir diferentes modalidades
- Definir objetivos semanais
- Consultar estatísticas
- Acompanhar a evolução do utilizador

---

## Modalidades Suportadas

- Brazilian Jiu-Jitsu (BJJ)
- MMA
- Boxe
- Muay Thai
- Musculação
